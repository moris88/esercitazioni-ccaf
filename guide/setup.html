Corso CCA-F · Setup

Guida al setup: Claude, Claude Code e il kit

Da seguire in ordine. Alla fine avrete l’app di Claude, Claude Code e le cartelle delle esercitazioni pronte sul vostro computer. Non serve saper programmare.

StrumentoChe cos’èServe per

L’account

  • Ognuno usa il proprio account Claude: l’accesso si fa una volta nell’app e una volta in Claude Code.
  • Claude Code richiede un piano Pro, Max, Team o Enterprise, oppure un account Console. La chat funziona con tutti i piani.
  • Le esercitazioni consumano un po’ del vostro piano.

Comandi e schermate possono cambiare. Se qualcosa non corrisponde, fa fede code.claude.com/docs (Claude Code) e support.claude.com (app).

1 · La chat

Installare e usare la chat

Installare l’app

  1. Aprite claude.ai/download e scegliete Windows o macOS.
  2. Aprite il file scaricato e completate l’installazione.
  3. Avviate Claude e fate l’accesso.

Non volete installare nulla? La stessa chat è su claude.ai, dal browser.

Le mosse di base

  • Una chat nuova per ogni esercitazione: la conversazione precedente non deve influenzare la risposta.
  • Allegare un file con il pulsante +, oppure incollarne il testo.
  • Copiare i riquadri grigi della guida così come sono e inviarli.
  • Riprovare: la risposta può cambiare da una prova all’altra. È normale.

2 · Claude Code

Installare Claude Code

Il terminale è una finestra in cui si scrivono comandi. Su Windows si chiama PowerShell, su Mac Terminale: cercatelo nel menu delle applicazioni.

Windows

  1. Installate Git for Windows da git-scm.com, lasciando le scelte proposte. Serve per l’hook di D1·3; non dovrete usarlo direttamente.
  2. Aprite PowerShell, incollate questa riga e premete Invio:
irm https://claude.ai/install.ps1 | iex

macOS

curl -fsSL https://claude.ai/install.sh | bash

Controllare

Chiudete e riaprite il terminale, poi scrivete:

claude --version

Se compare un numero, è installato.

2 · Claude Code

Preparare le cartelle e avviare

  1. Copiate cartella-prova e kit sul Desktop, dentro una cartella corso, una accanto all’altra.
  2. Aprite il terminale nella cartella-prova. Windows: aprite la cartella, clic destro in un punto vuoto, «Apri nel terminale». Mac: scrivete cd seguito da uno spazio, trascinate la cartella nel Terminale e premete Invio.
  3. Avviate Claude Code:
claude
  1. Al primo avvio si apre il browser: fate l’accesso e tornate al terminale.
  2. Claude chiede se vi fidate della cartella: rispondete sì.
corso/
  cartella-prova/   qui si avvia claude
    procedure/  ordini/  spedizioni/  risposte/  bozze/  riservato/
  kit/
    dati/           file da allegare in chat
    claude-code/    hook, regola, skill e subagente: li copia Claude

Usate sempre una copia. Se qualcosa si rovina, cancellate la vostra cartella-prova e ricopiate l’originale. Mai fare le esercitazioni in una cartella di lavoro.

2 · Claude Code

Usare Claude Code

Si scrive in italiano, come in chat. Prima di modificare un file o eseguire un comando Claude chiede il permesso: leggete che cosa vuole fare e poi rispondete.

Shift+TabCambia modalità: normale, accetta modifiche, plan

3 · Prima della lezione

Problemi comuni e checklist

SintomoChe cosa fare
claude non è riconosciutoChiudere e riaprire il terminale, poi provare claude doctor
Il login non va a buon fineVerificare il piano: quello gratuito non include Claude Code
L’hook non blocca nullaControllare /hooks e riavviare claude. Su Windows verificare che Git for Windows sia installato
Skill o subagente non compaionoVerificare di aver avviato claude in cartella-prova, poi /exit e riavviare
Claude non trova ../kitkit e cartella-prova devono stare una accanto all’altra
Il server MCP non si collegaControllare la connessione e aprire /mcp. Se non risponde, seguire D2·3 nel simulatore

Checklist

  • App di Claude installata, oppure claude.ai aperto, con accesso fatto
  • claude --version risponde
  • Accesso fatto in Claude Code
  • cartella-prova e kit una accanto all’altra
  • Su Windows: Git for Windows installato
